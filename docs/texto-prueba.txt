TypeScript es un lenguaje de programación desarrollado por Microsoft que se construye sobre JavaScript añadiendo un sistema de tipos estático. Todo programa válido de JavaScript es también un programa válido de TypeScript, pero el compilador de TypeScript comprueba los tipos antes de ejecutar el código y detecta errores que, de otro modo, solo aparecerían en tiempo de ejecución. Finalmente, el código TypeScript se transpila a JavaScript, que es lo que realmente ejecutan los navegadores y Node.js.

El sistema de tipos permite declarar el tipo de las variables, los parámetros de las funciones y los valores que devuelven. Los tipos básicos son string, number, boolean, null y undefined. También existen los arrays, que se escriben como number[] o Array<number>, y las tuplas, que son arrays de longitud fija con tipos distintos en cada posición. El tipo any desactiva la comprobación de tipos y conviene evitarlo, mientras que unknown obliga a comprobar el tipo antes de usar el valor.

Las interfaces y los alias de tipo describen la forma de un objeto. Una interfaz define las propiedades que debe tener, y cada propiedad puede ser obligatoria u opcional si se marca con un signo de interrogación. Los tipos unión, como string | number, permiten que un valor tenga uno de varios tipos, y el estrechamiento de tipos, mediante typeof o instanceof, ayuda al compilador a saber qué tipo concreto se está manejando en cada rama del código.

Las funciones pueden tener parámetros opcionales, valores por defecto y parámetros rest. Los genéricos permiten escribir funciones y clases reutilizables que funcionan con distintos tipos sin perder la seguridad de tipos; por ejemplo, una función identidad genérica devuelve el mismo tipo que recibe. Las clases admiten modificadores de acceso como public, private y protected, además de propiedades de solo lectura.

La configuración del compilador se guarda en el archivo tsconfig.json. La opción strict activa un conjunto de comprobaciones estrictas, como no permitir valores nulos implícitos, y se recomienda mantenerla activada. El comando tsc --noEmit comprueba los tipos sin generar archivos JavaScript, lo que resulta útil para verificar el código en integración continua.
